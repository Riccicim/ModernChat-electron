# ModernChat UI

A sleek and responsive chat interface built with **Tailwind CSS**, designed for web-based messaging applications. This project features animated message transitions, an interactive user list, and a stylish layout using custom utility classes and modern design principles.

## ✨ Features

- 💬 Modern chat layout with sender/receiver alignment
- 🧑‍🤝‍🧑 Sidebar with user avatars and online/offline status
- 🎨 Custom Tailwind CSS theme with gradient background
- 🎯 Smooth entrance animations for better UX
- 📱 Fully responsive design
